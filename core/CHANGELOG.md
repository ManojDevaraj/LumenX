# Changelog

## 0.4.0 — adaptive hybrid application core

- Added an optional Zero-DCE++ architecture and local checkpoint registry with explicit missing-weight fallback and provenance.
- Added illumination- and recoverability-aware fusion, deterministic twelve-candidate search, ablation controls, and one conservative guardrail repair.
- Added adaptive reports, nullable learned IQA metrics, and a no-reference fine-tuning script.
- Added hybrid, learned, and classical modes while preserving the v1.0 event and visual contract.

## 0.2.0 — classical vision milestone

- Added illumination, local-noise, SNR, hotspot, colour-cast, and clipping diagnosis; recoverability estimates; Retinex/CLAHE; guided denoising; safety audits; and custom metrics.

## 0.1.0 — interface foundation

- Added contract v1.0 types, run validation, deterministic FakeEngine, and a local image CLI.
