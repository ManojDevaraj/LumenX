        About the method

        How LumenX sees in the dark.

        LumenX first diagnoses a photo: where light is weak, how noisy it is, and how much real signal survived. It restores the scene with CIDNet, a deep model, then repairs blown highlights pixel by pixel, removes noise only where brightening amplified it, and audits the result with safety checks. Every step is shown, so the result can be inspected instead of trusted blindly.

        01Diagnose

        Measures light level, noise and how much signal was recorded.

        02CIDNet

        A deep model brightens the scene in a colour space built for low light.

        03Highlight repair

        Blends in a protected copy wherever lamps and windows would blow out.

        04Denoise

        Cleans grain only where the brightening amplified it.

        05Audit

        Checks highlights, colour shift, detail and halos, and reports every result.
